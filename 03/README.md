# 数智能源管理平台 · 3D 园区大屏

基于 Three.js 的园区能源管理可视化大屏首页，PC 与手机端通用，3D 建筑园区可旋转、缩放。

## 功能特性

- **3D 园区场景**：15 层主办公楼、7 / 8 层办公楼各一栋、配电间、休闲小花园（草坪 / 水池 / 长椅 / 绿化）
- **自由交互**：鼠标 / 触摸拖动旋转，滚轮 / 双指缩放
- **视角切换**：底部按钮一键飞切（总览 / 光伏 / 充电 / 空调 / 复位）
- **响应式布局**：PC 与移动端自适应，3D 场景与控件均正常可用

## 技术栈

- [Three.js](https://threejs.org/)（3D 渲染 + OrbitControls 轨道控制器）
- 原生 HTML + CSS（深色科技风主题）

## 本地预览

```bash
# 进入项目目录，启动一个静态服务器
python -m http.server 8080

# 浏览器打开
http://localhost:8080/index.html
```

> 也可以直接双击 `index.html` 用浏览器打开，但用本地服务器预览效果更稳妥（避免个别浏览器对本地文件的限制）。
