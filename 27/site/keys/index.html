🔑 NeonPlan 密钥助手Key Helper

NeonPlan 3D 能判断你当前在哪个房间——靠的是 Home Assistant 已有的蓝牙接收器。但 iPhone 和 Apple Watch 会不断更换蓝牙地址。为了仍能识别它们，NeonPlan 需要一次它们的密钥（IRK）。这一页把一块约 5 欧元的 ESP32 变成 NeonPlan 密钥助手，在配对时读取密钥——完全不需要 Mac。

我需要这个吗？
  • iPhone、Apple Watch：需要——除非你已经有密钥；那就直接在 NeonPlan 里「粘贴已有密钥」填入。
  • 安卓手机或平板：不需要——配对在这里也没用，安卓不会在后台发送密钥。请在 Home Assistant App 里打开设置 → 伴侣应用 → 管理传感器 → BLE 发射器，发射功率选高，广播模式选低延迟。这样 NeonPlan 就能自己找到手机。
  • 蓝牙防丢器（Nut、Tile、iBeacon）：不需要。AirTag 完全不支持，很遗憾。
你需要准备：
  • 一块 ESP32 开发板——普通 ESP32（「ESP32 DevKit」「ESP-WROOM-32」）、ESP32-C3 或 ESP32-S3，约 5 欧元
  • 一根能传输数据的 USB 线（有些充电线只供电、不传数据）
  • 一台装有 Chrome 或 Edge 的电脑（Firefox 和 Safari 无法刷写设备；手机和平板也不行）
  • NeonPlan 3D 2.0 及以上版本，以及你的 Wi-Fi 密码

操作步骤

1
插上 ESP32 并安装固件。用 USB 把 ESP32 接到电脑，点击下方的安装。在弹窗里选择 USB 端口（通常是「USB Serial」「CP210x」或「CH340」），确认安装。大约需要一分钟。

列表里没有端口？请看下方「遇到问题怎么办」。

2
填写 Wi-Fi。紧接着页面会询问你的 Wi-Fi。填入名称和密码——ESP32 会连上网络，配置完成。现在你也可以把它插到家里任意一个 USB 电源上。
3
在 Home Assistant 中添加。稍等片刻，Home Assistant 会发现新设备：设置 → 设备与服务 → 上方「已发现」里的 NeonPlan Key → 添加 → 提交。（如果没有提示：「添加集成」→ ESPHome → 填入 ESP32 的 IP 地址。）
4
在 NeonPlan 中打开。编辑器 → ⚙ 设置 → 📡 定位 → 2 · 设备。在 🔑 密钥助手下方现在会显示「已找到密钥助手：NeonPlan Key …」。
  • 选择 ⌚ 用于 Apple Watch 或 📱 用于 iPhone（助手会短暂重启）。
  • 填入一个名称（例如「小张的手表」）并选择成员。
5
配对。
  • Apple Watch：在手表上打开设置 → 蓝牙，稍等一会儿——「健康设备」下会出现 NeonPlan Key，点它。
  • iPhone：设置 → 蓝牙——在「其他设备」下点击 NeonPlan Key（它会以键盘身份出现；显示的配对码不需要输入）。

之后设备上常会显示「未连接」——这是正常的：助手拿到密钥后会主动断开连接。

6
采纳密钥。NeonPlan 中会出现「刚刚配对的设备所读取的密钥（IRK）」。点击添加为「…」——该设备就带着名称和成员出现在列表里。如果 NeonPlan 已认识这个密钥，那里会显示「属于：…」。
7
清理。在手表或 iPhone 上点击 NeonPlan Key → ⓘ → 「忽略此设备」。
8
要配下一台设备？先在 NeonPlan 里点击 🔄 下一台设备（助手会换一个新的蓝牙标识，避免上一台设备又插进来），然后从第 4 步重新开始。

安装

此浏览器无法刷写设备——请在电脑上使用 Chrome 或 Edge。 请通过 https 打开本页面。

遇到问题怎么办

弹窗里没有出现 USB 端口
  • 换一根 USB 线——很多线只供电、不传数据。
  • 缺少驱动（Windows）：CP210x 芯片的板子装 Silicon Labs 驱动，CH340 的装 WCH 驱动，然后重新插拔。
  • 有些板子启动时需要按住 BOOT 键：按住它，同时点击「安装」。
Home Assistant 找不到「NeonPlan Key」
  • ESP32 和 Home Assistant 在同一个网络里吗（不是访客 Wi-Fi）？
  • 手动添加：设置 → 设备与服务 → 添加集成 → ESPHome → 填入 ESP32 的 IP 地址（在你路由器的设备列表里能看到）。
手表上没有显示「NeonPlan Key」
  • NeonPlan 里必须选择 ⌚ 用于 Apple Watch（配置文件「心率带」）。切换后等 20 秒。
  • 在手表蓝牙页面稍等一会儿，向下滚动到「健康设备」。
  • 如果之前有别的设备配对过：在 NeonPlan 里点 🔄 下一台设备。
显示「未连接」，密钥一直不变
  • 通常是之前配对过的设备（比如 iPhone）反复自动连回来。在那台设备上把「NeonPlan Key」→ ⓘ → 忽略此设备，然后在 NeonPlan 里点 🔄 下一台设备，重新配对。
  • 如果显示「属于：…」，说明这个密钥已经在 NeonPlan 里了——刚才配对的是已知设备。
之后还能做什么？

这块 ESP32 你可以留着（配更多设备），也可以把它重新刷成 ESPHome 蓝牙代理——那样它甚至能辅助定位：ESP32 代理大约每秒上报一次，Shelly 只能每三到四秒上报一次。

NeonPlan 3D finds out which room you are in – from the Bluetooth scanners Home Assistant already has. An iPhone and an Apple Watch keep changing their Bluetooth address, though. So that NeonPlan recognises them anyway, it needs their key (IRK) once. This page turns an ESP32 for about 5 € into the NeonPlan Key Helper, which reads the key while the device pairs – no Mac needed.

Do I need it?
  • iPhone, Apple Watch: yes – unless you have the key already; then enter it in NeonPlan under "Paste a key you already have".
  • Android phone or tablet: no – and pairing does not help here, Android does not send the key in the background. Switch on Settings → Companion app → Manage sensors → BLE Transmitter in the Home Assistant app, with transmit power High and advertise mode Low latency. NeonPlan then finds the phone by itself.
  • Key tags (Nut, Tile, iBeacon): no. AirTags do not work at all, sadly.
You need:
  • an ESP32 board – a plain ESP32 ("ESP32 DevKit", "ESP-WROOM-32"), ESP32-C3 or ESP32-S3, about 5 €
  • a USB cable that carries data (some charging cables only carry power)
  • a computer with Chrome or Edge (Firefox and Safari cannot flash devices; phones and tablets do not work)
  • NeonPlan 3D 2.0 or newer and your Wi-Fi password

How it works – step by step

1
Plug in and install. Plug the ESP32 into the computer and click Install below. Pick the USB port in the window (usually "USB Serial", "CP210x" or "CH340") and confirm Install. It takes about a minute.

No port in the list? See "If something does not work" below.

2
Enter your Wi-Fi. Right afterwards the page asks for your Wi-Fi. Enter name and password – the ESP32 connects and is done. You can now plug it into any USB charger in the house.
3
Add it in Home Assistant. After a moment Home Assistant reports a new device: Settings → Devices & services → under "Discovered" NeonPlan Key → Add → Submit. (No message? "Add integration" → ESPHome → enter the ESP32's IP address.)
4
Open it in NeonPlan. Editor → ⚙ Settings → 📡 Locating → 2 · Devices. Under 🔑 Key helper it now says "Key helper found: NeonPlan Key …".
  • Pick ⌚ For an Apple Watch or 📱 For an iPhone (the helper restarts briefly).
  • Enter a name (e.g. "Torsten's watch") and pick the person.
5
Pair.
  • Apple Watch: on the watch Settings → Bluetooth, wait a moment – NeonPlan Key shows under "Health devices". Tap it.
  • iPhone: Settings → Bluetooth – tap NeonPlan Key under "Other devices" (it shows as a keyboard; a code shown need not be typed).

The device often says "Not connected" afterwards – that is right: the helper drops the connection as soon as it has the key.

6
Take it over. NeonPlan shows "Key (IRK) read from the device that just paired". Tap Add as "…" – the device is now in the list with its name and person. If NeonPlan knows the key already, it says "Belongs to: …".
7
Tidy up. On the watch or iPhone tap NeonPlan Key → ⓘ → "Forget This Device".
8
Next device? First tap 🔄 Next device in NeonPlan (the helper gets a new Bluetooth identity, so the device before does not connect in between), then go on from step 4.

Install

This browser cannot flash devices – please use Chrome or Edge on a computer. Please open this page over https.

If something does not work

No USB port shows in the window
  • Try another USB cable – many only charge and carry no data.
  • Missing driver (Windows): for boards with CP210x install the Silicon Labs driver, for CH340 the WCH driver, then plug in again.
  • Some boards need the BOOT button: hold it while you click "Install".
Home Assistant does not find "NeonPlan Key"
  • Is the ESP32 on the same network as Home Assistant (not the guest Wi-Fi)?
  • By hand: Settings → Devices & services → Add integration → ESPHome → the ESP32's IP address (your router shows it).
The watch does not show "NeonPlan Key"
  • ⌚ For an Apple Watch must be picked in NeonPlan (profile "heart rate sensor"). Wait 20 seconds after switching.
  • On the watch wait a little in Bluetooth and scroll down to "Health devices".
  • If another device paired before: tap 🔄 Next device in NeonPlan.
"Not connected" and the key does not change
  • Usually a device paired before (the iPhone, say) keeps connecting by itself. Forget "NeonPlan Key" there (ⓘ → Forget This Device), tap 🔄 Next device in NeonPlan and pair again.
  • If it says "Belongs to: …", the key is in NeonPlan already – the device that paired was a known one.
And afterwards?

Keep the ESP32 (for more devices) or flash it as an ESPHome Bluetooth proxy – then it even helps locating: ESP32 proxies report about every second, Shellys only every three to four seconds.
